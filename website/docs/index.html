第一次使用

跟着三步走，不需要碰命令行。遇到问题可以直接到 GitHub Issues 反馈。

1. 安装应用

从 下载页 选择对应系统的安装包。Windows 双击 .exe；macOS 打开 .dmg 后拖进「应用程序」；Linux 安装 .deb，或给 AppImage 赋执行权限后直接运行。

2. 准备推理引擎

首次启动会引导安装推理引擎。日常对话推荐 llama.cpp，它运行 GGUF 模型，兼容性最好；需要运行 MNN 量化模型时，再单独安装 MNN 引擎。应用、引擎、模型三层相互独立，安装引擎不会重新下载整个应用。

安装过程有实时进度和失败原因。如果 GitHub 拉取超时，应用内置了国内镜像；也可以在设置中切换下载源。

3. 下载并运行模型

打开「模型市场」，搜索想用的模型。卡片上会标出模型体积、推荐引擎和运行内存，按你的硬件选择合适的量化档。点「下载模型」，进度完成后回到对话页选择该模型即可。

如果卡片提供两个按钮，含义分别是：安装引擎准备运行环境，下载模型获取权重文件。两者互不替代，第一次使用通常都要完成。

常用操作

  1. Ctrl/⌘ + K：打开命令面板，模糊搜索任意功能。
  2. Ctrl/⌘ + /：查看全部快捷键。
  3. 设置中可切换深色 / 浅色主题、中文 / 英文，以及模型与引擎的存放目录。
  4. 模型市场支持收藏与最近使用，方便固定常用模型。
  5. Agent 页可查看深度思考卡：展开后能看到推理步骤、工具名称与调用参数。

常见问题

装引擎一直转圈？ 多数是网络拉取 GitHub 超时。先等待重试，或在设置里切换下载源；仍失败可在日志页查看具体错误。

模型下载一半断了？ 重新点击下载会从断点续传，不需要从头开始。

Mac 提示无法打开？ 到「系统设置 → 隐私与安全性」允许打开；如果仍被拦截，右键应用选择「打开」。

该装 llama.cpp 还是 MNN？ 优先 llama.cpp，GGUF 生态最完整。需要更小的量化模型、或在特定 ARM / 国产硬件上运行时，再选 MNN。

遇到问题？到 GitHub Issues 提反馈，附上系统版本、应用版本与日志片段，会更快定位。
