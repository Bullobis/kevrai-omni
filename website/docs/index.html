第一次使用

跟着三步走，不需要碰命令行。

1. 安装

从 下载页 选对应系统的安装包。Windows 双击 .exe，macOS 打开 .dmg 拖进应用程序，Linux 装 .deb 或直接跑 AppImage。

2. 准备引擎

首次启动会引导你装一个推理引擎。日常对话推荐 llama.cpp（跑 GGUF 模型，兼容性最好）；有国产 NPU 或想跑 MNN 量化模型再装 MNN。安装是一条进度条，后台自动拉取，失败会提示原因。

3. 下载并运行模型

打开「模型市场」，搜索你想聊的模型。页面会根据你的内存/显存推荐合适的量化档。点下载，进度走完后在对话页选择即可。

常用操作

  1. Ctrl/⌘ + K：命令面板，模糊搜任何功能。
  2. Ctrl/⌘ + /：查看全部快捷键。
  3. 设置里可切换深色/浅色主题、中文/英文、模型与引擎存放目录。
  4. 模型市场支持收藏与最近使用，筛选你常用的。

常见问题

装引擎一直转圈？ 多为网络拉取 GitHub 超时。应用已内置国内镜像，若仍慢可在设置里换下载源。

模型下载一半断了？ 重新点下载会从断点续传，不会从头再来。

Mac 提示无法打开？ 到「系统设置 → 隐私与安全性」点"仍要打开"。

遇到问题？去 GitHub Issues 提反馈，会附上你的环境信息，我们会跟进修复。
