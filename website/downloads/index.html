BEFORE YOU INSTALL

安装前需要知道的三件事

01RUNTIME

不需要预装 Python

应用自带独立 sidecar 运行时。首次启动会在后台准备环境，不污染系统 Python，也不需要命令行。

02ENGINE

先装引擎，再下模型

日常对话推荐 llama.cpp；需要 MNN 量化模型时再单独安装 MNN 引擎。两者可以同时存在。

03STORAGE

给模型留出磁盘空间

安装包不含大模型。模型按需下载，单个模型从几百 MB 到数百 GB，建议预留充足空间。

macOS 首次打开提示“无法验证开发者”？ 到「系统设置 → 隐私与安全性」允许打开即可。Linux 的 AppImage 需要先赋予执行权限： chmod +x Kevrai-Omni-4.18.3-x86_64.AppImage。
