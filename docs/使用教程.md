# MiniMax H3 Studio 使用教程

> 面向零基础用户。全程只需要双击两个文件：**一键启动.bat**（日常使用）和 **一键打包.bat**（做成安装包）。

---

## 一、压缩包里有什么

```
压缩包
├── 使用教程.md          ← 你正在看的文件
└── H3Studio/            ← 源代码文件夹（所有功能都在这里）
    ├── 一键启动.bat      ← ★ 日常使用：双击直接运行软件（免打包）
    ├── 一键打包.bat      ← ★ 打包成 EXE 安装包
    ├── h3studio/        ← 程序源码
    ├── resources/       ← 内置 ComfyUI 工作流等资源
    ├── packaging/       ← 安装包脚本
    ├── requirements.txt ← 依赖清单
    └── README.md        ← 功能说明书
```

## 二、准备工作（只做一次）

1. **安装 Python 3.10 ~ 3.14**（推荐 **3.12 或 3.13**，兼容性最稳）
   下载：https://www.python.org/downloads/
   ⚠️ 安装第一屏务必勾选 **"Add python.exe to PATH"**，再点 Install Now。
   ⚠️ 不要装 Python 3.15：PyTorch 还没有适配 Windows 版（2026-08 核实）。

2. **解压压缩包**
   ⚠️ **强烈建议解压到纯英文路径**，例如：
   - ✅ `D:\H3Studio`
   - ❌ `C:\Users\小明\桌面\H3Studio源码`（中文路径）
   - ❌ `C:\Users\小明\OneDrive\桌面\...`（OneDrive 同步目录）

   为什么？中文路径和 OneDrive 同步是打包报错的两大元凶（详见第六节）。

3. **磁盘空间**：预留 15GB 以上（依赖约 5GB + 模型 35GB 起，模型可放其他盘）。

## 三、一键启动（日常使用）

双击 `H3Studio\一键启动.bat`：

- 第一次运行会自动装环境：PyTorch 约 2.5GB + 应用依赖，约 5~15 分钟（国内镜像，自动续装，中断了重新双击即可接着装）
- 之后每次双击秒开

软件打开后三步出片：

1. **模型市场**页：顶部"🎯 你的电脑最优方案"卡片已经算好了最适合你电脑的版本 → 点 **一键下载推荐方案**（自动测速选最快下载源，断点续传）
2. **生成**页：写提示词（不会写就点"快捷模板"选一个模板），拖入参考图/视频/音频（可选）
3. 点 **开始生成**（或按 Ctrl+Enter）。右下角可切换 ⚡速度优先 / ⚖均衡 / ✨质量优先 三档

生成的视频在 **作品库** 页查看播放，文件保存在 `C:\Users\你的用户名\H3Studio\outputs`。

## 四、打包成 EXE 安装包（可选）

想把软件做成安装包发给别人：

1. 先安装免费的 **Inno Setup 6**：https://jrsoftware.org/isdl.php （一路下一步即可）
2. 双击 `一键打包.bat`，等待约 10~20 分钟
3. 产物：
   - **安装包**：`packaging\Output\H3Studio-Setup-x.x.x.exe`（发给别人双击安装）
   - **绿色版**：`dist\H3Studio\H3Studio.exe`（免安装直接运行）

不装 Inno Setup 也能打包，只是只有绿色版没有安装包。

## 五、没有 NVIDIA 显卡怎么办

软件会自动检测你的硬件（NVIDIA / AMD / 华为昇腾 / Intel），并如实告诉你支持程度：

- **NVIDIA**：完整支持，内置引擎直接推理（推荐）
- **AMD**：Linux + ROCm 为官方支持路线；Windows 下建议走 ComfyUI 路线——软件"我的模型"页内置了官方社区工作流，一键复制粘贴到 ComfyUI 即可用
- **华为昇腾**：内置引擎支持（需 torch-npu 环境）
- **无加速硬件**：可正常使用模型市场/作品库等功能，本地推理跑不动

## 六、常见问题

**Q1：在桌面解压后运行打包报错？**
三大原因按概率排序：
1. **路径含中文**（"桌面"两个字就是中文）→ 把文件夹移到 `D:\H3Studio` 这类纯英文路径
2. **OneDrive 同步目录**（很多电脑的"桌面"实际在 OneDrive 里）→ 移出 OneDrive
3. 路径含空格 → 一般没事，但结合上面两条就容易出错
脚本启动时会自动体检路径并提醒你。

**Q2：安装依赖很慢/失败？**
应用依赖走清华镜像（失败自动换腾讯源）；PyTorch 必须走官方 CUDA 源（约 2.5GB，慢也要等完，中断重跑会续装）。
注意：PyTorch 不能用国内 PyPI 镜像装——镜像会把 torch 匹配成 CPU 版，装了也用不上显卡。

**Q2.1：我的 Python 版本多少合适？**
3.10~3.14 都行，推荐 3.12/3.13。Python 3.15 暂时别用（PyTorch 的 Windows 版还没支持）。

**Q3：提示"未找到 Python"？**
重装 Python，记得勾选 Add to PATH；装完**重新打开**命令行窗口再试。

**Q4：生成时提示引擎未就绪？**
打开软件"设置"页看"推理引擎环境"卡片的提示，缺什么装什么。

**Q5：爆显存 / 速度太慢？**
- 生成页切 ⚡速度优先档（480P + Turbo LoRA 加速）
- 设置页点"⚡ 应用推荐配置"让软件按你的硬件重新配
- 长视频分段出：先出 5 秒确认效果，再拉时长

**Q6：模型下载到一半断了？**
直接在模型市场再点一次下载，自动从断点继续。

**Q7：杀毒软件误报？**
PyInstaller 打包的程序偶发误报，属已知现象；添加信任即可，有条件可给安装包做代码签名。

## 七、硬件与速度速查

| 你的配置 | 建议 | 预期（社区实测参考） |
|---|---|---|
| RTX 5090 / 4090 24G+ | BF16 或 NF4 全速 | 480P/5s ≈ 1~2 分钟 |
| RTX 4060Ti 16G / 4080 | NF4 双分区 | 768P 5~7s 稳定 |
| RTX 3060 12G | NF4 + 480P 起步 | 480P/5s ≈ 9 分钟 |
| 8G 显存 | NF4 FL2VA + 速度优先档 | 慢但能跑 |
| 无 N 卡 | ComfyUI 路线（内置工作流） | 视硬件而定 |

速度数据来源与更多细节见软件内"模型市场"页的推荐卡片（每条都标注了实测来源）。
