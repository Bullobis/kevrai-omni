# 小白使用手册

这份手册假设你**完全没用过命令行**，也没配过 Python、显卡驱动这些东西。
按顺序往下做就行，遇到报错直接翻到最后一节「常见报错对照表」。

---

## 第 0 步：先体检（最重要，30 秒）

**不管你遇到什么问题，都先跑这一步。** 它会告诉你这台电脑缺什么、该怎么补。

### Windows

1. 在 Kevrai Omni 的安装目录里找到 `scripts` 文件夹
2. 在文件夹地址栏输入 `cmd` 然后回车，会弹出一个黑窗口
3. 复制粘贴下面这行，回车：

```
python scripts\health_check.py
```

### macOS / Linux

打开「终端」，进到项目目录，粘贴：

```
python3 scripts/health_check.py
```

### 看到的结果怎么看

报告每一项前面有个标记：

| 标记 | 意思 | 你要做什么 |
|---|---|---|
| `[OK]` | 没问题 | 不用管 |
| `[!!]` | 警告 | 能用，但这项会影响体验，**建议处理** |
| `[XX]` | 失败 | **必须修**，不修软件跑不起来 |
| `[--]` | 跳过 | 这台机器没这项，忽略 |

每一项下面都写了「**怎么修**」，把里面的命令整行复制粘贴执行就行。

### 想把报告发给别人求助

```
python scripts/health_check.py --md 体检报告.md
```

会生成一个 `体检报告.md` 文件，直接发给帮你排查的人。

> 如果你完全离线（不能上网），加 `--no-network` 跳过联网那一项：
> `python scripts/health_check.py --no-network`

## 第 1 步：安装与启动

- **Windows**：去 Releases 下载 `Kevrai-Omni-xxxx-x64.exe`，双击安装，
  桌面会出现快捷方式。
- **macOS**：下载 `.dmg`，把图标拖进 Applications。
  第一次打开如果系统拦了，去「系统设置 → 隐私与安全性」点「仍要打开」。
- **Linux**：下载 `.AppImage`（双击）或 `.deb`（双击用软件中心装）。

启动后如果提示「没有 Python」，点一下「**一键安装 Python 环境**」就好，
它装在你自己的用户目录里，**不会动你系统里别的东西**。

---

## 第 2 步：装引擎 → 下模型 → 开始用

按软件里的顺序走这三步：

1. **装引擎**：「AI 引擎」页，选一个（比如 llama.cpp），点安装。
   引擎就是"跑模型的程序"，模型是"数据"，两个都要有。
2. **下模型**：「模型市场」里挑一个模型点下载。支持中文搜索。
3. **开始用**：对话 / 生图 / 生视频 / 语音，选好模型、写提示词、点生成。

### 不知道选哪个模型？

**看你的显卡显存**（体检报告里「显卡 / 加速卡」那一项会写）：

| 你的显存 | 建议 |
|---|---|
| 没有独立显卡（纯 CPU） | 选名字里带 0.5B / 1B / 1.5B 的小模型 |
| 4~6 GB | 选 3B ~ 7B 的模型，量化档选 Q4 |
| 8 GB | 7B ~ 14B，量化档 Q4 或 Q5 |
| 12~16 GB | 14B ~ 32B，量化档 Q5 |
| 24 GB 以上 | 32B 以上随意，量化档 Q6 / Q8 |

> **量化档是什么？** 简单理解成"压缩率"。Q4 压得最狠、体积最小、画质略降；
> Q8 体积大、质量最好。不确定的话选 **Q4_K_M**，是公认的均衡档。

## 第 3 步：下载慢 / 总断线怎么办

v4.11.0 起下载会自动**分片并发**：大文件切成几段同时下，断线后
**已完成的分段不用重下**。你什么都不用设置，它自己会判断。

什么时候会失效？**服务器不支持断点续传时**（少数小站点）。
这时它会自动退回原来的单线方式，不会变慢 —— 只是没了加速。

### 国内下载建议

- **优先用魔搭（ModelScope）源**：不需要登录、不需要令牌，速度通常比 HuggingFace 快。
  模型市场里带魔搭地址的条目，下载时选魔搭就行。
- HuggingFace 打不开时，`hf-mirror.com` 镜像会自动作为备选。

### 磁盘不够

体检报告会明确告诉你剩余空间。注意**单个大模型常常 10~60 GB**，
留 20 GB 以下基本下不完。空间不够就换个盘当数据目录。

## 第 4 步：国产显卡用户看这里

v4.11.0 起，下面这些卡**能被认出来了**（以前一律显示"未识别到独立显卡"）：

- 摩尔线程（MTT 系列）
- 天数智芯（CoreX 系列）
- 寒武纪（MLU 系列）
- 海光（DCU 系列）
- Intel 独立显卡 / 数据中心加速卡

**想让它认得更准（能显示显存大小）**，需要装厂商自己的管理工具：

| 你的卡 | 要装什么 |
|---|---|
| 摩尔线程 | MUSA 驱动包，装完有 `mthreads-smi` |
| 天数智芯 | CoreX 软件栈，装完有 `ix-smi` |
| 寒武纪 | CNToolkit，装完有 `cnmon` |
| 海光 | DCU 驱动，装完有 `hy-smi` |
| Intel | oneAPI / XPU 驱动，装完有 `xpu-smi` |

**不装也能用**：软件会用系统信息兜底认出卡的型号，只是显存大小显示不出来。
但要跑模型，驱动本身还是得装的。

> 认出来之后能不能跑，取决于对应推理引擎有没有适配这个平台。
> 目前生态最成熟的是 NVIDIA（CUDA）和 Apple（Metal）。

## 常见报错对照表

| 你看到的 | 原因 | 怎么修 |
|---|---|---|
| 提示"不是内部或外部命令"（Windows） | Python 没装或没加到 PATH | 重装 Python，安装时**务必勾选 Add Python to PATH** |
| `ModuleNotFoundError: No module named xxx` | 依赖没装 | `python -m pip install -r python/requirements.txt` |
| pip 装得极慢 / 超时 | 连的是国外源 | 命令末尾加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `npm install` 很慢 | 同上 | 先执行 `npm config set registry https://registry.npmmirror.com` |
| 启动时报端口被占用 | 8800 端口被别的程序占了 | 关掉那个程序，或换端口：Windows 执行 `set KEVRAI_SIDECAR_PORT=8801` |
| 下载到一半失败 | 磁盘满了，或网络断了 | 重开下载会自动续传；先看体检报告的磁盘那一项 |
| 体检报告说磁盘不足 20GB | 真的不够 | 清磁盘，或设 `KEVRAI_DATA_ROOT` 指向更大的盘 |
| 显卡显示"未识别" | 驱动没装，或是不在支持列表 | 装对应厂商驱动；国产卡见上一节 |
| 模型市场点了下载却 404 | 该模型地址有误或未开放权重 | 换魔搭源；条目上标注"暂无可下载权重"的就是官方还没放出来 |

---

## 三个"别担心"

1. **装在用户目录，不动系统**：Python、引擎、模型都在你自己的用户数据目录里，
   卸载软件删掉那个目录就干净了。
2. **下载中断不会前功尽弃**：分片续传会跳过已完成的部分。
3. **体检脚本只依赖标准库**：哪怕你一个依赖都没装，它也能跑起来告诉你缺什么。
